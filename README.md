# 🌊 Flood Health Analyser
### Disaster Health Monitoring System

## 📌 About the Project
The Flood Health Analyser is an educational prototype designed to explore health monitoring during flood situations and other disasters, when access to medical assistance may be limited.

The project combines an ESP32 microcontroller, a MAX30102 sensor module, and a web-based dashboard to demonstrate the collection and presentation of health-related readings.

## 🎯 Objectives
- Explore sensor-based health monitoring using ESP32.
- Measure pulse-related signals using the MAX30102 sensor.
- Develop a web dashboard to display health-related information.
- Explore how readings could be shared with medical teams when connectivity is available.

## 🛠️ Hardware Components
- ESP32 development board
- MAX30102 sensor module
- Breadboard and jumper wires
- LEDs and resistors
- USB data cable

## 💻 Technologies
- Arduino IDE
- C/C++ for ESP32 firmware
- HTML, CSS and JavaScript, where applicable

## ⚙️ Working Principle
1. The MAX30102 sensor connects to the ESP32.
2. The ESP32 communicates with the sensor using I2C.
3. The web dashboard provides an interface to display health-related information.
4. Hardware-to-dashboard communication can be integrated to support live readings.

## 🚀 Future Improvements
- Integrate live sensor readings with the webpage.
- Explore offline data storage and synchronization.
- Improve the dashboard for emergency-response scenarios.
- Evaluate the reliability of sensor measurements.

## ⚠️ Disclaimer
This is an educational prototype, not a certified medical device. It must not be used for medical diagnosis or treatment.
